# YOLOv8 Plastic Detection System

A deep learning-based object detection system that identifies and classifies three types of plastic waste: **Masks**, **Bags**, and **Bottles**. Built with YOLOv8 and deployed with a user-friendly Streamlit web interface.

## Project Structure
- `app.py`: Streamlit web interface
- `Project.ipynb`: Model training, data augmentation, and evaluation pipeline
- `requirements.txt`: Python package requirements
